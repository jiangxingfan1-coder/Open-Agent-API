## ACP agent preset metadata (`src/config/agent-presets.ts`)

The ACP preset catalog (command names, arguments, maturity, documentation links) is ported from the same author's Possibility project (`src/agent-presets.ts`, `shared/agent-onboarding.ts`). The command metadata in it is adapted from [Open Design](https://github.com/nexu-io/open-design), Copyright 2026 Open Design contributors, Apache-2.0 (`licenses/OpenDesign-APACHE-2.0.txt`): the Vibe command shape comes from Open Design commit `b40f25a1c89552725f1fc31f8c2fad172f92acfe`; Kimi Code follows its current vendor ACP documentation; the version-pinned `npx` and binary distributions come from the public [ACP Registry](https://cdn.agentclientprotocol.com/registry/v1/latest/registry.json).

Statement of changes (Apache-2.0 section 4(b)): for OAA it was rewritten as "display and discovery only" metadata: no model probing, no MCP injection, no credential handling, no package installation, no automatic enabling or execution; presets that use an `npx` launcher are not discovered or run; the descriptive text was rewritten to match OAA's actual behavior. The file header keeps the attribution above.

Verification record (2026-11-10): the launch commands of all 32 presets in the catalog were checked one by one against the vendor's own documentation or the official ACP registry, and the `source_url` of every record points to the official page used for the check (the official Trae CLI documentation has moved to docs.trae.cn). This check corrected the pinned versions of two registry launchers, GLM and Grok, and removed `--accept-hooks` from the Hermes preset (that argument automatically approves shell hooks that have not been confirmed yet). The attribution and license statements above are unchanged.

Additional note: "presets that use an `npx` launcher are not discovered or run" means that OAA never downloads or executes those packages with `npx`; the three presets `claude-acp`, `codex-acp` and `codebuddy` look for an already installed executable of the same name on `PATH`, and once found they can be enabled explicitly by an admin.

The ACP client (`src/engines/acp.ts`) is a minimal JSON-RPC implementation written independently against the public Agent Client Protocol v1 specification; it does not ship or copy any code of `@agentclientprotocol/sdk`, and during development the SDK (Apache-2.0) was consulted only through the `schema.json` it publishes, to check field names.

## Node.js runtime (release installers)

The installers on GitHub Releases bundle the official Node.js runtime (for the version see `NODE_RUNTIME_VERSION` in `.github/workflows/release.yml`, taken from https://nodejs.org/dist/ and verified against `SHASUMS256.txt`), containing only the `node` executable (`node.exe` on Windows), unmodified (re-signed on macOS to satisfy Gatekeeper). Node.js is released under the MIT license, Copyright Node.js contributors; the licenses of the third-party components bundled in it (V8, libuv, OpenSSL, ICU and so on) are listed in the same file. The full `LICENSE` is distributed with the installer: on macOS in `Open Agent API.app/Contents/Resources/node/LICENSE`, on Windows in `runtime\LICENSE`. This does not apply when running from source.

The public release installers do not include `@anthropic-ai/claude-agent-sdk` (nor its platform packages, nor `@anthropic-ai/sdk`, which only it references); users must install the Claude native engine's dependency separately, see [docs/releasing.md](docs/releasing.md).
