# 本地互联

[English](../local-connections.md) · 简体中文

本地互联是独立于 API 密钥生成的模块。首批接收端为 DeepSeek Harness（DSH）：所有者选择已经发布的源智能体，查看预览并确认，OAA 自动创建专用密钥并向 DSH 添加提供方。不替换原提供方，不改变当前会话，不自动发布智能体，也不改变原有 API 密钥流程。

## 范围

- 仅允许直接回环连接、所有者全域管理员密钥、本机执行节点、本地安全配置及 HTTP 网关。公网或经代理的管理请求不能写客户端文件。
- 支持使用标准 settings-file、credentials-local 和 llm-pi-ai 的 DSH 桌面组合。自定义或停用的存储需手动配置。
- 向 DSH 共享的 `settings.yaml` 添加一个 `llm-pi-ai.providers.oaa-*` 条目，向 `.credentials.yaml` 添加一个 `refs.OAA_DSH_*` 值。使用这两个存储的配置档共享此提供方。现有 `profiles/desktop/cordis.patch.yml` 不变。DSH 文件提供方支持热加载；如果文件监听漏过通知，仍可能需要重载客户端。
- 密钥仅具有选定源智能体的读取、调用和文件权限，数据范围为调用方自身。工具执行方式默认遵循发布设置，没有设置时使用服务端执行；仅提供源能力及发布策略均支持的方式。客户端模式桥接 DSH 工具，服务端模式使用源智能体工具，混合模式允许两端工具。无法证明工具隔离的原生源不提供“仅客户端工具”。切换方式需要确认修复密钥，不能悄悄同步授权。密钥不授予管理或审批权限。操作确认仍服从源发布的发布者/原生规则。原生源智能体仍以可信宿主权限执行，并非操作系统沙箱。
- 拒绝 DSH 源、通过声明的委派/协作者通向 DSH 的源，以及指回当前网关的本地模型提供方或 HTTP 适配器。无法穷尽检查闭源原生行为或远程配置中的循环。

## 生命周期

客户端配置文件限制为 4 MiB。编辑路径中的共享 YAML 锚点/别名，以及为托管条目新增的注释，会被拒绝改写而不是丢失；不相关的注释和锚点会保留。预览固定本次属于新增授权、同步还是修复，提交前再次验证管理员权限。密钥被撤销后，已经确认的同步不能悄悄变成新授权。

断开不会取消已经受理的任务。修复会替换专用密钥，因此旧调用方身份下的资源可能仍需原密钥访问。不会自动授予协作者或委派智能体的权限；需要额外智能体授权的组合工作流仍可使用独立 API 密钥流程。

预览不创建密钥，不写客户端配置。应用时再次核对源智能体与文件版本，使用 DSH 相同的 `<file>.lock` 写锁，通过同目录原子替换先写凭据、再写提供方。不抢占已有锁。遇到无效 YAML、不安全文件类型、不安全凭据权限或外部修改时，不覆盖问题文件。首次写入备份位于网关私有的 `local-connections/backups/` 目录，可能包含凭据，必须保持私密。

重复应用同一预览不会重复建密钥。同步仅更新本模块拥有的提供方，复用原密钥；修复失效密钥时先撤销旧专用授权，再创建替代密钥。日志用于协调被中断的安装/同步操作；密钥上的来源标记让恢复过程可撤销尚未来得及记录日志的孤立授权。连接元数据不存明文密钥，连接 API 也不返回它。

断开时，即使外部修改阻止清理，也会撤销专用密钥。只删除仍与记录指纹一致的条目；外部修改保留，并显示冲突。不用整份旧文件覆盖较新的其他修改，也不改动其他 API 密钥。

连接检查仅直接访问回环地址的模型元数据接口，不走进程代理环境变量。它**不等于**生成、模型授权或质量验证。由于智能体请求可能产生副作用，提供方级自动重试被关闭。模型列表是已发布目录的快照；发布、模型列表或网关端口变化后需要同步，不自动切换已有会话。

## API

可选能力 `local-connections-v1` 声明以下所有者本机操作：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/v1/local/connections` | 目标可用性、源选择及连接状态 |
| POST | `/v1/local/connections/preview` | `{agent, model, tool_mode?}`；模型默认 `auto` |
| POST | `/v1/local/connections/apply` | 同一管理员尚未过期预览的 `{plan_id}` |
| POST | `/v1/local/connections/{id}/check` | 不生成内容的接口、密钥和模型元数据检查 |
| DELETE | `/v1/local/connections/{id}` | 撤销密钥并按指纹清理拥有的条目 |

首版不自动配置 Codex 或 Claude 客户端。要求在沙箱中执行宿主工具的发布需要单独验证的连接，不自动配置。不升级第三方软件包，也不承诺闭源智能体的工具隔离。
