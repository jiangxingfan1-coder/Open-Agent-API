# 本地互联

[English](../local-connections.md) · 简体中文

本地互联以可搜索的卡片列出本机客户端，点击卡片打开配置弹窗。自动配置支持 **API 自动接入**（`dsh`、`opencode`、`codex`）与 **MCP 桥一键注入**（`claude-desktop`、`cursor`、`windsurf`、`claude-code`）双通道：选择已发布的源智能体（MCP 桥也可选择全部已发布智能体），查看变更摘要预览并确认，OAA 自动创建仅具最小权限（`read`、`invoke`、`files`，绝无 `approve` 或 `admin`）的专用密钥并保存在私有的 `0600` 密钥文件中，先备份原文件再原子合并受管条目，绝不覆盖客户端原有的其他提供方、MCP 服务或当前会话。

## 客户端检测

- 检测范围包括原生/ACP 目录、已配置的可执行文件或脚本入口、固定安装目录、已知 macOS 应用及常见 VS Code/Cursor/Windsurf 扩展目录。仅检查安装元数据，不启动智能体、不下载包、不登录、不读取凭据、私人项目或历史记录，不发模型提示或额度查询。通用包管理器和残留设置目录不能作为安装证据。
- 同一产品的原生与 ACP 入口合并，Claude Desktop 与 Claude Code 分开。找到命令、应用或扩展不代表已登录、有模型额度、协议兼容或正在运行；任意自定义安装位置仍需显式配置入口。
- 页面支持“已检测到 / 全部”、搜索及重新检测。API 保留原有 `target`、`sources`、`data` 字段并增加 `clients`；`?refresh=1` 绕过 30 秒元数据缓存。仍要求所有者管理员、宿主执行权限、直接回环连接和同源检查。
- DSH 支持自动配置。Codex、Claude Code、OpenCode、Qoder 桌面端提供手动接入弹窗，可选择源智能体与模型、复制地址、查看官方文档并进入原有密钥向导，尚不自动写入它们的配置。仅安装 Qoder CLI 不承诺支持任意自定义端点。其他卡片明确显示接收端暂未适配，源智能体设置仍在本机后端。手动接入不享有 DSH 自动配置的循环检查和撤销保证。

手动接入依据官方的 [Codex 配置](https://developers.openai.com/codex/config-advanced/)、[Claude 网关](https://code.claude.com/docs/en/llm-gateway)、[OpenCode 提供方](https://opencode.ai/docs/providers/) 和 [Qoder 自定义模型](https://docs.qoder.com/qoder/custom-models) 文档；实际兼容性仍取决于安装版本及源智能体能力。

## 范围

- 仅允许直接回环连接、所有者全域管理员密钥、本机执行节点、本地安全配置及 HTTP 网关。公网或经代理的管理请求不能写客户端文件。
- 支持使用标准 settings-file、credentials-local 和 llm-pi-ai 的 DSH 桌面组合。自定义或停用的存储需手动配置。
- 向 DSH 共享的 `settings.yaml` 添加一个 `llm-pi-ai.providers.oaa-*` 条目，向 `.credentials.yaml` 添加一个 `refs.OAA_DSH_*` 值。使用这两个存储的配置档共享此提供方。现有 `profiles/desktop/cordis.patch.yml` 不变。DSH 文件提供方支持热加载；如果文件监听漏过通知，仍可能需要重载客户端。
- 密钥仅具有选定源智能体的读取、调用和文件权限，数据范围为调用方自身。工具执行方式默认遵循发布设置，没有设置时使用服务端执行；仅提供源能力及发布策略均支持的方式。客户端模式桥接 DSH 工具，服务端模式使用源智能体工具，混合模式允许两端工具。无法证明工具隔离的原生源不提供“仅客户端工具”。切换方式需要确认修复密钥，不能悄悄同步授权。密钥不授予管理或审批权限。操作确认仍服从源发布的发布者/原生规则。原生源智能体仍以可信宿主权限执行，并非操作系统沙箱。
- 拒绝 DSH 源、通过声明的委派/协作者通向 DSH 的源，以及指回当前网关的本地模型提供方或 HTTP 适配器。无法穷尽检查闭源原生行为或远程配置中的循环。

## 生命周期

客户端配置文件限制为 4 MiB。编辑路径中的共享 YAML 锚点/别名，以及为托管条目新增的注释，会被拒绝改写而不是丢失；不相关的注释和锚点会保留。预览固定本次属于新增授权、同步还是修复，提交前再次验证管理员权限。密钥被撤销后，已经确认的同步不能悄悄变成新授权。

断开不会取消已经受理的任务。修复会替换专用密钥，因此旧调用方身份下的资源可能仍需原密钥访问。不会自动授予协作者或委派智能体的权限；需要额外智能体授权的组合工作流仍可使用独立 API 密钥流程。

预览不创建密钥，不写客户端配置。应用时再次核对源智能体与文件版本，使用 DSH 相同的 `<file>.lock` 写锁，通过同目录原子替换先写凭据、再写提供方。不抢占已有锁。遇到无效 YAML、不安全文件类型、不安全凭据权限或外部修改时，不覆盖问题文件。首次写入备份位于网关私有的 `local-connections/backups/` 目录，可能包含凭据，必须保持私密。

重复应用同一预览不会重复建密钥。同步仅更新本模块拥有的提供方，复用原密钥；修复失效密钥时先撤销旧专用授权，再创建替代密钥。日志用于协调被中断的安装/同步操作；密钥上的来源标记让恢复过程可撤销尚未来得及记录日志的孤立授权。连接元数据不存明文密钥，连接 API 也不返回它。

断开时，即使外部修改阻止清理，也会撤销专用密钥。只删除仍与记录指纹一致的条目；外部修改保留，并显示冲突。不用整份旧文件覆盖较新的其他修改，也不改动其他 API 密钥。

连接检查仅直接访问回环地址的模型元数据接口，不走进程代理环境变量。它**不等于**生成、模型授权或质量验证。由于智能体请求可能产生副作用，提供方级自动重试被关闭。模型列表是已发布目录的快照；发布、模型列表或网关端口变化后需要同步，不自动切换已有会话。

## API

可选能力 `local-connections-v1` 声明以下所有者本机操作：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/v1/local/connections` | 目标可用性（`target` 与 `targets`）、源选择及连接状态 |
| POST | `/v1/local/connections/preview` | `{target?, channel?, agent?, model?, tool_mode?}`；默认 `target: "dsh"`、`model: "auto"` |
| POST | `/v1/local/connections/apply` | 同一管理员尚未过期预览的 `{plan_id, target?, channel?}` |
| POST | `/v1/local/connections/{id}/check` | 不生成内容的接口、密钥和目标元数据检查 |
| DELETE | `/v1/local/connections/{id}` | 撤销专用密钥、删除私有密钥文件并按指纹清理拥有的条目 |

API 自动配置向 OpenCode 原子合并 `provider["open-agent-api"]`（通过 `{file:<私有密钥路径>}` 引用），向 Codex 追加或更新独立的 `[model_providers.oaa]` 段（拒绝自环接入与复杂冲突 TOML 语法）。MCP 一键注入向目标配置写入 `mcpServers["open-agent-api"]` 并通过 `--token-file` 传入网关私有 `0600` 密钥文件，绝不在客户端 JSON 中暴露明文裸令牌。要求在沙箱中执行宿主工具的发布需要单独验证的连接，不自动配置。
